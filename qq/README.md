# QQ 群文字排队（开发预览）

推荐使用 QQ 开放平台官方机器人；步骤见 [OFFICIAL-BOT.md](OFFICIAL-BOT.md)。已有备用 QQ 账号的用户可继续参考 [NapCat / NoneBot2 旧版接入](NONEBOT2.md)。

此目录包含官方 QQ 排队适配、早柚核心排队插件和旧版 OneBot 群消息门禁。群内须使用 QQ 的真实 `@机器人` 消息段开头，例如 `@有神的机器人 排队` 或 `@有神的机器人 zzz查询安比`；手打“@机器人昵称”不会触发。QQ 红包尚未接入。无需 Docker。

绝区零账号绑定、角色养成度等查询建议由早柚核心的 [ZZZeroUID](https://github.com/ZZZure/ZZZeroUID) 承担。它支持 `zzz绑定UID`、`zzz查询`、`zzz练度统计` 等指令。这里的 QQ 排队插件不绑定 QQ 与 B 站身份；两者只按同名合并。

以下手动安装步骤仅适用于旧版 NapCat / OneBot 方案；官方机器人使用上面的独立指南。

1. 在直播电脑控制台填写直播间 ID、要使用的 QQ 群号，开启免费排队，然后勾选「启用 QQ 群文字排队」并保存。只有启用免费排队时，普通 QQ 成员的文字「排队」才会入队。
2. 将 `gsuid_queue` 目录复制到早柚核心源码的 `gsuid_core/plugins` 目录。把 `settings.example.json` 复制为 `settings.json`，将本机控制台显示的 QQ 接入令牌填入 `token`。两个服务在同一电脑时，`queue_url` 使用排队程序实际端口（可在 `data/runtime.json` 查看）。
3. 为早柚核心连接一个可接收群消息的 QQ 机器人适配器，并将机器人加入指定群。按 [NoneBot2 指南](NONEBOT2.md)安装 `mention_gate.py` 后，启动早柚核心与本插件，在群里发送真正的 `@机器人 排队` 测试。不带 @ 的「排队」应保持静默且不入队。

队列仍按原有规则排序：中奖置顶、大航海身份、礼物金额、先到先得。QQ 昵称/群名片与 B 站昵称相同时会合并同一条记录；QQ 消息不会覆盖已知的 B 站 UID。请要求成员的群名片与 B 站昵称完全一致，因为同名有冒用风险。

接口只接受本机请求、配置的群号与令牌，并依据群消息 ID 去重。`settings.json` 含私密令牌，不要上传至 GitHub。QQ 红包金额没有经过真实适配器事件验证，不会自动记账。
