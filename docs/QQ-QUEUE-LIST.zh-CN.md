# QQ 群查看排队列表

群成员真正 @机器人后发送 `/排队列表`，例如：`@然神🤖 /排队列表`。

机器人返回当前叫号观众、等待人数及最多前 20 位等待观众，显示金额和红包待核对状态。顺序与直播排队挂件一致：中奖置顶、舰队身份、金额、先到先得；查询不会叫号或修改队列。超过 20 人时显示其余人数。

查看列表不需要绑定 B站账号，入队仍必须先 `/绑定B站` 并完成短弹幕验证。本群必须已绑定主播，且主播助手保持在线。

**更新范围：**真实 @ 回复只需更新公共机器人服务器，主播不需要更新；`/排队列表` 需要服务器和主播端同时更新。旧版主播端会收到明确升级提示。替换主播端程序时保留原 `data` 目录，不需要重新绑定群或观众账号。
