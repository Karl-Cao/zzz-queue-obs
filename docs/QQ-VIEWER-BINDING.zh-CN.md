# 观众验证绑定 Bilibili UID 与 QQ 身份

主播先连接公共机器人并绑定本群，确保 LAPLACE Event Bridge 正在接收自己直播间的弹幕。主播电脑需要保持排队助手运行。

1. 在主播的 QQ 群里真正 @「然神🤖」，发送 `/绑定B站`。不需要填写 B站 UID、昵称或任何账号凭据。
2. 机器人会回复短弹幕，例如 `绑定123456`（数字每次不同）。在5分钟内，用要绑定的 B站账号，在主播直播间发送这8个字符；不加空格，不需要在B站发送斜杠或@机器人。助手会从真实弹幕事件自动读取发送者UID和昵称。不要把验证码转给别人。

3. 助手收到真实短弹幕后，会自动同步身份并在QQ群真正 @你回复验证成功，无需发送 `/查看绑定`。该口令仍可用于主动查询状态。
4. 以后真正 @机器人发送 `/排队`，使用该 B站 UID 与现有队列合并，礼物金额继续累计，首次入队的等待时间保留。叫号时按验证后的 UID 找到 QQ 成员并真正 @。

不要发送账号密码、Cookie 或身份码。机器人收到的是 QQ 开放平台的成员 OpenID，无法读取真实 QQ 号码。绑定使用这个身份，改 QQ 昵称不会解除绑定。同群一个 B站 UID 只能绑定一个 QQ 身份，不同群的绑定互相隔离。

主播端每分钟自动读取本直播间完整舰队名单，按 B站 UID 识别总督、提督、舰长。无需定期发弹幕，舰队到期从名单消失后，会在下一次成功同步时自动失去身份和优先级。重启后助手会自动拉取名单。

排序：总督 > 提督 > 舰长 > 礼物金额 > 先到先得；抽奖中奖者仍固定在接下来第一位。舰队成员即使主播关闭免费排队，也可以在 QQ 免费入队。首次验证绑定仍需要一条验证码弹幕，证明账号所有权。

控制台「连接与规则」显示舰队同步时间、人数和错误。接口失败或分页不完整不会用半份名单覆盖旧名单；旧数据最多保留5分钟的权限，之后暂停授予舰队优先级，继续自动重试。无需填写 B站 Cookie；公开接口可能被限流，不能保证秒级到期更新，也不提供每位成员的准确到期日期。

主播可在「连接与规则」分别填写语音叫号词和 QQ 群叫号词。`{name}` 替换观众昵称，`{uid}` 替换用户码；留空使用默认语言的叫号词。QQ 自动附加真正的 @，无需自行写 @标签。

解除：真正 @机器人发送 `/解绑B站`。重新绑定：重复以上验证码流程，验证成功前保留原绑定。解除或修改绑定不会自动删除已在队列中的记录。

昵称绑定已取消。主播端必须升级到1.12.3或以上，才能处理无需UID的验证流程；只更新公共服务器不足以完成验证。

主播需要解除群绑定时，用当初私聊确认绑定的QQ账号，私聊机器人发送 `/解绑群`。有多个群时按提示指定群号或绑定标识。该操作只解除自己的群与主播助手连接，不删除本地队列。

短验证码仍需本地Event Bridge收到真实弹幕；公共服务器更新无法代替主播端升级。重启后重新申请验证码。

旧的自行填写昵称绑定会由公共服务器自动清除，无需逐个用户手动解绑；已通过弹幕验证的真实UID绑定保留。旧昵称用户重新发送 `/绑定B站` 完成短弹幕验证即可。该清理只需服务器更新。

群内排队和红包申报必须先完成真实B站绑定，并等待自动验证成功通知。未绑定时仅允许绑定及查询等非排队口令；服务器会阻止未绑定用户入队，包括旧主播端。新版主播端另作本地校验，服务器缓存无法替代本地验证。

## 升级保留身份

已验证身份独立保存在主播端 `data/qq-identities.json`，同时兼容旧 `data/state.json` 的迁移。升级到新目录时复制完整data，包括公共连接凭据；不要只复制一个文件。重连同一群或服务器缓存重建后，助手自动恢复已验证身份，无需群成员重新发验证码。验证码是临时的，重启后重新申请；已验证身份不会因此丢失。

QQ群需允许机器人主动发言，否则成功通知可能被QQ拒绝。身份同步仍会保存，通知会重试，控制台显示原因。

取消等待：群内真正 @机器人发送 `/取消排队`，或使用同一已绑定B站账号在直播间发送 `取消排队`。已在当前位时请联系主播处理。
