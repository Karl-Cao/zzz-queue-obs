# 叫号时分享游戏登录二维码（v1.13.0）

这项功能读取主播电脑上**绝区零游戏客户端的扫码登录界面**，把其中的二维码发送到已绑定的QQ群。它不使用 `/扫码登录` 获取 Cookie 的二维码，也不生成游戏登录凭据。

## 第一次设置

1. 确认主播助手已连接公共机器人并绑定目标群。为保证观众身份可匹配，观众应先完成 `/绑定B站`。
2. 在绝区零客户端打开扫码登录界面。在 OBS 中添加游戏捕获或窗口捕获来源，确认来源画面能看到完整二维码；黑屏时先修复捕获。
3. OBS → 工具 → WebSocket 服务器设置：启用服务器，保留身份验证，记下端口和密码。
4. 在直播电脑打开主播助手完整控制台（不是 `/overlay`），找到「游戏登录二维码」。填写 OBS 端口和密码，读取来源列表，选择游戏来源。
5. 获取画面，用鼠标框选完整二维码，稍微保留四周边缘，保存配置。游戏窗口或二维码位置变化后，需要重新框选。
6. 点击识别测试。检查预览中只有清晰的二维码；这一步不会叫号，也不会向群里发消息。

OBS 密码保存在主播电脑的 `data/game-qr.json`，不传给公共服务器。不要分享这个文件。手机控制台可以操作发送按钮，来源和区域需先在直播电脑配置。

## 每次使用

1. 打开游戏扫码登录界面，刷新二维码。
2. 点击「完成当前 · 叫号并发送登录码」。助手先读取新画面并检查二维码，然后完成当前任务，叫下一位，向绑定群发送叫号及二维码。
3. 观众确认图片注明的是自己，使用自己的米游社 App 扫码，并确认登录的是主播电脑上的游戏。群内所有成员均能看到图片，请勿代扫。
4. 图片过期或发送失败时，先在游戏里刷新，再点击「重发当前登录码」。这不会完成当前任务或重复推进队列。

二维码识别失败或获取后队列发生变化时，不会推进。若叫号已完成、随后群图片发送失败，页面会提示重发；不要再点完成当前。

本功能只在点击时读取指定 OBS 来源，发送裁剪后的二维码，不持续截屏，不保存二维码到磁盘，也不上传完整游戏画面。30秒的发送令牌用于防止过旧预览被使用，**不代表游戏二维码仍有效**；有效期由游戏决定。

## 验证范围和更新范围

自动测试使用合成图片验证识别、裁剪、权限、群路由、过期、防重复以及发送失败后不重复推进。已在测试群 168426621 人工验收真实游戏码：OBS 捕获与裁剪、QQ 图片显示、米游社扫码后电脑端绝区零登录成功；重发不推进队列，也不重复语音。其他主播首次使用仍应先测试自己的 OBS 捕获与群发送权限。

这项新功能需要同时更新主播端和公共机器人服务器；早柚核心与 ZZZeroUID 无需为此更新。未使用新按钮的旧主播端继续使用原有排队和叫号功能。
