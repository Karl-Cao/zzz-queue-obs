# 主播端与服务器更新范围

## 主播端版本 1.12.3

等待列表中点击「指定叫号」，可跳过排名直接叫指定观众。原当前观众回到等待队列，保留金额、首次入队时间和优先级，不记为完成；所选观众成为当前，触发语音及已绑定QQ群通知；其他人金额、等待时间和排序不变。支持限时撤销，但撤销不会撤回已经播放的语音或QQ消息。待核对红包占位记录必须先完成核对，不能直接叫号。悬浮窗按 Ctrl+Alt+Q 进入操作模式，再点击对应行的「叫号」。

指定叫号需要更新主播端。它沿用已有服务器叫号接口，服务器无需为此升级。

| 改动 | 是否必须更新主播端 | 服务器负责的部分 |
| --- | --- | --- |
| 指定叫号、控制台按钮、悬浮窗布局 | 必须 | 沿用已有群通知接口 |
| 排序规则、礼物金额、抽奖、等待时间 | 必须 | 无权威队列逻辑 |
| B站弹幕解析、验证弹幕规则、舰队同步 | 必须 | 可转发绑定口令、缓存验证结果 |
| 自定义叫号词、Windows TTS、OBS挂件 | 必须 | 将主播生成的文字发到QQ群 |
| 红包核对界面、实际金额入账规则 | 必须 | 接收金额申报并转发 |
| 主播群绑定界面与提示 | 必须 | 私聊授权及群绑定校验可独立更新 |
| QQ口令前缀检查、错误提示 | 通常无需；控制台/指南提示变动仍需更新 | 可直接在公共机器人更新，例如强制 / 和取消昵称绑定入口 |
| QQ消息发送、真实@格式、权限报错 | 无需，只要已有接口不变 | 服务器更新即可 |
| 绝区零查询修复、ZZZeroUID升级、美术资源 | 无需 | 服务器更新依赖并按需下载素材 |
| QQ菜单新增已支持的ZZZ查询口令 | 无需 | 更新指令面板与查询处理 |
| 新排队口令但仍映射已有排队请求 | 通常无需 | 保持原有请求格式及本地排队规则 |
| 新排队功能、增加必需字段或改变接口 | 可能两端都需要 | 应保留旧协议或明确最低主播版本 |
| HTTPS域名、隧道、部署及密钥 | 通常无需换包；地址变化需修改控制台设置 | 由运营者管理 |

服务器单独升级不能修改别人电脑上的本地队列逻辑、页面、TTS或UID验证规则。新增菜单项也不代表功能已实现。

## 实施与升级

1. 服务器兼容原有 /client/* 接口时，可以独立更新，不要求主播换包；排队仍需要主播电脑在线。
2. 主播端升级先退出旧版，解压新版到新目录，复制旧版 data，再启动；不要同时运行两份。
3. 已验证身份及设置保存在 data，验证码仅在内存，重启后应重新申请。
4. 本机源码运行服务已同步；GitHub下载包不会自动改变。v1.12.0发布包尚未含斜杠提示及指定叫号；1.12.1发布包已包含这些修复及指定叫号，旧包需升级才能获得本地功能。

1.12.3：无需UID的B站验证和短弹幕生成需要更新主播端；私聊 `/解绑群` 由服务器提供，旧主播端无需升级即可使用，但重新绑定时仍应按最新斜杠提示操作。
