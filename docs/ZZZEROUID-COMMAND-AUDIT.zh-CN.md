# 公共机器人 ZZZeroUID 指令检查（2026-10-01）

检查对象为 Oracle 正式服务器，不是旧 Windows 托管实例。早柚核心使用 `87c06f1`，ZZZeroUID 使用 `7774832`。

## 结果

插件共注册 36 个处理函数、38 个匹配器、99 个不同的指令名或别名。对每个注册名加 `/zzz` 检查实际公共转发规则，未发现被入口漏接的已实现命令。24 个插件服务均启用，没有服务黑白名单限制；其中 3 个服务具有管理员权限要求。

初次检查时 QQ 平台的单张面板列出 20 条指令。随后按用户要求简化为 10 条入口并通过 QQ API 回读确认：7 条排队/绑定口令，加 `/zzz帮助`、`/zzz绑定UID`、`/扫码登录`。面板沿用原标识以保持兼容，绝区零详细功能从 `/zzz帮助` 查看；未在面板出现的命令仍可手输。

以下为常用的完整功能入口。群内必须真正 @机器人，所有口令带 `/`；统一推荐小写 `zzz`。公开入口不接受 `/绝区零…` 前缀，尽管上游插件内部支持该前缀。

## 管理员功能

`/zzz全部重签` 与 `/zzz强制推送体力提醒` 要求核心权限等级 1；`/zzz下载全部资源` 要求等级 2。它们已接入，但普通群成员不能按普通查询权限使用。群主身份不自动等于公共机器人的核心管理员。

## 发现的问题

1. 原面板把 `/zzz深渊` 描述为“查询危局强袭”，实际应为式舆防卫战；危局强袭应使用 `/zzz强袭战`。简化后的面板不再列出该条错误描述，命令本身仍可手输。
2. 面板未列出的已实现功能包括切换/删除游戏UID、便签、临界推演、绳网月报、音擎/驱动盘/邦布/怪物资料、高难关卡资料、抽卡刷新、自动服务设置等。它们可以手输，不能把“没预览”理解为“没接入”。
3. 上游尚未注册独立的 `/zzz音擎攻略`、`/zzz突破材料`，现有公共入口会明确提示不支持；音擎介绍和角色图鉴中包含相应材料资料。
4. `/绑定信息`、`/绑定设备`、`/ck帮助` 是早柚核心的内置账号命令，不是 ZZZeroUID 注册指令；目前公共入口未开放它们。`/扫码登录` 是已有的特殊开放入口。
5. 上游帮助配置存在不够准确的凭据标注/例子，例如部分需要UID或Cookie的操作被标作不需要，且“深渊信息”的例子写成“深渊”。实际命令处理代码优先于帮助图上的说明。

本次验证的是注册、转发和服务启用覆盖，并读取了 QQ 平台实际面板；没有逐一操作真实用户的账号修改、签到、抽卡刷新和订阅，也没有声称所有外部接口已通过运行验收。正式帮助图查询已在核心升级时验证。
